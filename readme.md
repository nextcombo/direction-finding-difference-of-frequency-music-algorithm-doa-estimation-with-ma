# [Direction Finding]Difference of Frequency MUSIC Algorithm DOA Estimation [with MATLAB Code]

Introduction: Due to spatial aliasing, uniform linear arrays (ULAs) constrain the estimation of the direction of arrival (DOA) of plane waves to a higher frequency range. To account for specific frequency components in the data, sampling should occur at more than two points per wavelength. Otherwise, the DOA becomes ambiguous, leading to incorrect component placement in the wrong DOA. This issue is particularly pronounced when dealing with out-of-band signals at higher frequencies.
We address high-frequency DOA estimation and employ multi-frequency processing. The use of additional data from multiple frequencies within a broadband signal enables increased processing gain and improved estimation [1], [2], [3], [4]. For better broadband DOA estimation, sparse signal reconstruction has been proposed [5], [6], [7], [8], [9], [10]. Another technique based on cyclicity in the signal is another approach, leveraging temporal and spatial cyclic correlation characteristics [11], [12], [13], [14], [15]. Using the spectral properties of multiple frequency points, improvements have been made to the well-known non-uniform ULA - the mutually orthogonal array (MOA) DOA estimation [16], [17], [18], [19].
Multi-frequency processing utilizes differential frequency (DF), where the array data at frequency f is multiplied by the complex conjugate of the data at another f + Δf, enabling the handling of data from lower frequency Δf regions without spatial aliasing [20], [21]. The DOA estimation of far-field sources is modeled using both plane wave and array data models.
DF technology has been applied to source localization and DOA estimation, with experimental data verification [21], [22], [23], [24]. For source localization, matching field processing has been applied, using wave propagation models for matching measurements and simulated signals [25], [26], [27], [28]. For DOA estimation, conventional beamformers (CBF) or delay-summing beamformers [21] have been used. High-frequency DF methods show comparable DOA performance to low-frequency CBFs [22]. Improving the DOA performance of CBF based on DF through inverse filtering [23] and further analysis considerations [24]. As shown in the figure, DF processing uses Hadamard product of array data at frequency f and complex conjugate data at f + Δf.
This paper proposes three methods for combining multiple time and directional samples for combine harvester: time, frequency, and time-frequency. Time-DF-MUSIC uses multiple time samples for single DF to obtain the time average sample covariance matrix (SCM). The use of DF can generate spurious DOA [21], [22], [24] that depend on true DOA and DF frequency. Since spurious DOA vary with DF on DF, obtaining MUSIC spectrum for each DF separately and averaging over frequencies can alleviate spurious.
Frequency-DF-MUSIC uses multiple DF with uniform intervals having the same DF to obtain the frequency average SCM. For true DOA, constant DF shares the same steering vector and multiple DF is equivalent to multiple snapshots. Frequency processing employs multiple DF to achieve single snapshot DOA estimation. Single time snapshot method is useful for time-varying wave arrival direction.
Time-frequency DF-MUSIC combines all time and DF samples into SCM. This method utilizes more data averaging to improve DOA estimation.

Conclusions: A method for DOA estimation of multiple frequency high-frequency sources and their difference frequencies to obtain low-frequency processing is proposed. Since DF is lower than the overlapping frequency, there is no spatial overlap. The time-DF-MUSIC algorithm combines time samples into the sample covariance matrix to obtain MUSIC spectra at each DF and averages these spectra to estimate the final DOA. The frequency-DF-MUSIC is suitable for a single snapshot and does not require fixed DOA over time. The time-frequency-DF-MUSIC algorithm integrates all the time-frequency information and uses more data to achieve processing gain.
